Privacy policy

Last updated: 2026-10-20

rclone ThinkPad is a private backup tool used only by its owner, on the owner's own computer.

What data the app accesses

The app uses the Google Drive scope drive.file. It can see only the files and folders that it created itself in the owner's Google Drive. It cannot see any other files.

How the data is used

The app stores and restores backup copies of the owner's own files. Nothing else.

Storage and sharing

Access tokens are stored only on the owner's computer. Data is sent only between that computer and Google Drive. No data is sold, shared with third parties, or used for advertising.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

Access can be revoked at any time at myaccount.google.com/permissions. The backup files can be deleted directly in Google Drive.

Contact

Through the GitHub profile of the owner of this repository.
